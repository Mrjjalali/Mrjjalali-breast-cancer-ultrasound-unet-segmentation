#  Breast Cancer Ultrasound Image Segmentation using U-Net

سیستم سگمنتیشن تصاویر اولتراسوند سرطان سینه با استفاده از معماری U-Net پیاده‌سازی‌شده از صفر با TensorFlow/Keras.

## معرفی پروژه

این پروژه با هدف شناسایی و جداسازی دقیق نواحی مشکوک به تومور در تصاویر اولتراسوند سینه طراحی شده است. با استفاده از معماری U-Net، مدل به‌صورت پیکسل‌به‌پیکسل (Semantic Segmentation) مرز ضایعات را از بافت سالم تفکیک می‌کند.

##  دیتاست

از دیتاست عمومی **BUSI (Breast Ultrasound Images Dataset)** استفاده شده است:

- ۷۸۰ تصویر اولتراسوند از ۶۰۰ بیمار
- سه دسته: Normal (۱۳۳ تصویر)، Benign (۴۳۷ تصویر)، Malignant (۲۱۰ تصویر)
- هر تصویر همراه با ماسک (Ground Truth) ترسیم‌شده توسط رادیولوژیست
- دانلود از طریق کتابخانه‌ی `kagglehub`
- منبع: [Kaggle - BUSI Dataset](https://www.kaggle.com/datasets/aryashah2k/breast-ultrasound-images-dataset)

##  پیش‌پردازش داده

- **جداسازی تصاویر اصلی از فایل‌های ماسک** بر اساس نام فایل (فیلتر کردن فایل‌هایی که کلمه‌ی `mask` در نامشان است)
- **ترکیب چندماسکی:** برای تصاویری که بیش از یک ناحیه‌ی ضایعه (و در نتیجه چند فایل ماسک جداگانه) دارند، تمام ماسک‌ها با عملیات OR منطقی (`np.maximum`) با هم ترکیب شده‌اند
- **مدیریت تصاویر بدون ضایعه:** برای تصاویر دسته‌ی Normal که ماسک واقعی ندارند، یک ماسک کاملاً سیاه هم‌اندازه‌ی تصویر اصلی تولید می‌شود
- **Resize:** تمام تصاویر و ماسک‌های متناظر به سایز ثابت **۱۲۸×۱۲۸** پیکسل تغییر اندازه داده شدند
- **باینری‌سازی مجدد:** پس از resize، ماسک‌ها با threshold=127 دوباره باینری شدند (برای رفع اثر interpolation)
- **نرمال‌سازی:** مقادیر پیکسلی تصاویر ورودی به بازه‌ی [۰,۱] نگاشت شدند

##  معماری مدل

معماری U-Net استاندارد با ۴ سطح Encoder و ۴ سطح Decoder:

| بخش | جزئیات |
|---|---|
| Encoder | ۴ سطح Downsampling (دو Conv2D + MaxPooling در هر سطح) با فیلترهای ۱۶ → ۳۲ → ۶۴ → ۱۲۸ |
| Bottleneck | ۲۵۶ فیلتر |
| Decoder | ۴ سطح Upsampling (Conv2DTranspose) با Skip Connections به لایه‌های متناظر Encoder، فیلترهای ۱۲۸ → ۶۴ → ۳۲ → ۱۶ |
| خروجی | Conv2D با کرنل ۱×۱ و فعال‌سازی Sigmoid |
| تعداد کل پارامترها | ۱,۹۴۰,۸۱۷ (~۷.۴ MB) |
